# Universe for Mac

Native Electron desktop editions for Universe science classroom. Both load the corresponding HTTPS course site in their own sandboxed window; no separate browser installation is required. Course content requires internet.

The workflow builds universal DMG installers for Apple Silicon and Intel on macOS. Download a DMG from Releases, open it, and drag the app to Applications. These builds are not Developer ID signed or notarized; macOS may require confirmation in Privacy & Security before first launch. Do not disable Gatekeeper globally. Projector use requires an external display configured as an extended desktop.

Source contains only the desktop wrapper and icons, not lesson assets or credentials.
